# Reliable Properties

Static property-detail website prepared for GitHub Pages.

## Structure

- `index.html` — property page
- `assets/css/styles.css` — responsive styles
- `assets/js/main.js` — menu and enquiry interactions
- `assets/images/` — optimized representative property photography
- `IMAGE_CREDITS.md` — image sources and usage note
- `.github/workflows/pages.yml` — GitHub Pages deployment

## Preview locally

Open `index.html` in a browser, or run a simple local web server from this folder.

## Publish

Push the repository to GitHub. The included workflow publishes the `main` branch to GitHub Pages.
